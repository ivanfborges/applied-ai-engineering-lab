# References and Further Reading

## Books and Course Notes

- Gilbert Strang, *Introduction to Linear Algebra*, 6th edition, Wellesley-Cambridge Press, 2023. Geometric and computational treatment of vectors, matrices, linear systems, and transformations.
- Gene H. Golub and Charles F. Van Loan, *Matrix Computations*, 4th edition, Johns Hopkins University Press, 2013. Authoritative reference for numerical matrix algorithms and stability.
- MIT OpenCourseWare, [18.06 Linear Algebra](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/). Lectures, assignments, and notes covering core linear algebra.
- Stanford CS229, [Linear Algebra Review](https://cs229.stanford.edu/section/cs229-linalg.pdf). Compact review connecting linear algebra to machine learning.

## Official Documentation

- NumPy, [`numpy.matmul`](https://numpy.org/doc/stable/reference/generated/numpy.matmul.html). Matrix multiplication semantics and broadcasting behavior.
- NumPy, [Linear algebra routines](https://numpy.org/doc/stable/reference/routines.linalg.html). Norms, solvers, decompositions, and related operations.
- SciPy, [Sparse arrays](https://docs.scipy.org/doc/scipy/reference/sparse.html). Sparse representations and operations.
- scikit-learn, [Pairwise metrics, affinities and kernels](https://scikit-learn.org/stable/modules/metrics.html#metrics). Euclidean, cosine, and other pairwise computations used in ML workflows.

## Applied AI Connections

- Vaswani et al. (2017), [Attention Is All You Need](https://arxiv.org/abs/1706.03762). Introduces scaled dot-product attention and its matrix formulation.
- Johnson, Douze, and Jégou (2017), [Billion-scale similarity search with GPUs](https://arxiv.org/abs/1702.08734). Describes large-scale vector similarity search and the FAISS system.

## Notes About This Module

The examples use synthetic vectors embedded directly in the scripts. No public dataset is used, and no benchmark result is claimed.
