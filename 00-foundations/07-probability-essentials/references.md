# References

## Probability foundations

- Joseph K. Blitzstein and Jessica Hwang, *Introduction to Probability*,
  second edition. The [Harvard Statistics 110 site](https://stat110.hsites.harvard.edu/)
  links to the free online book, lectures, and practice material. Useful for
  conditional probability, Bayes' theorem, expectation, and variance.
- MIT OpenCourseWare,
  [18.05 Introduction to Probability and Statistics](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/).
  Course notes, exercises, and lectures covering core probability and
  statistical reasoning.
- Sheldon Ross, *A First Course in Probability*, Pearson. A standard reference
  for event algebra, conditional probability, random variables, expectation,
  and common distributions.
- Kevin P. Murphy, *Probabilistic Machine Learning: An Introduction*, MIT
  Press, 2022. See the
  [official book page](https://probml.github.io/pml-book/book1.html) for the
  connection from probability foundations to modern machine learning.

## Library documentation used by the examples

- [NumPy random sampling](https://numpy.org/doc/stable/reference/random/):
  `Generator` and reproducible pseudo-random simulation.
- [NumPy `var`](https://numpy.org/doc/stable/reference/generated/numpy.var.html):
  variance calculation and the `ddof` convention.
- [pandas `crosstab`](https://pandas.pydata.org/pandas-docs/stable/reference/api/pandas.crosstab.html):
  contingency-table construction.
- [Matplotlib `savefig`](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.savefig.html):
  saving generated figures.
- [Matplotlib `PillowWriter`](https://matplotlib.org/stable/api/_as_gen/matplotlib.animation.PillowWriter.html):
  GIF export without ImageMagick or FFmpeg.
- [Plotly Python graphing library](https://plotly.com/python/): interactive
  2D, Sankey, and 3D charts used by the visual lab.
- [Streamlit API reference](https://docs.streamlit.io/develop/api-reference):
  application layout, widgets, caching, tables, media, and Plotly rendering.

## Scope and data provenance

The practical example uses only synthetic binary observations generated by
NumPy with a fixed random seed. It does not use a public dataset and does not
report benchmark results. The fraud rate, true-positive rate, and
false-positive rate are hypothetical values chosen to demonstrate the
base-rate effect.
