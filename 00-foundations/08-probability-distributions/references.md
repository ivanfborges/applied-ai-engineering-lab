# References

## Books

- Casella, G., and Berger, R. L. *Statistical Inference*. 2nd ed., Duxbury,
  2002. Probability models, likelihood, estimation, and statistical inference.
- Murphy, K. P. *Probabilistic Machine Learning: An Introduction*. MIT Press,
  2022. Probabilistic modeling and connections to machine-learning objectives.
  The author provides an [official book page and downloadable
  material](https://probml.github.io/pml-book/book1.html).
- Ross, S. M. *A First Course in Probability*. 10th ed., Pearson, 2019.
  Discrete and continuous distributions and Poisson processes.

## Technical Documentation

- NIST/SEMATECH, [Probability
  Distributions](https://www.itl.nist.gov/div898/handbook/eda/section3/eda36.htm).
  Definitions, parameter estimation, and a gallery of common distributions.
- NIST/SEMATECH, [Binomial
  Distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda366i.htm).
- NIST/SEMATECH, [Poisson
  Distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda366j.htm).
- NIST/SEMATECH, [Exponential
  Distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3667.htm).
- NIST/SEMATECH, [Normal
  Distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3661.htm).
- NIST/SEMATECH, [Lognormal
  Distribution](https://www.itl.nist.gov/div898/handbook/eda/section3/eda3669.htm).
- NumPy, [Random
  Sampling](https://numpy.org/doc/stable/reference/random/index.html). Official
  API documentation for the seeded synthetic sampling used by `example.py`.
- Matplotlib, [Histograms](https://matplotlib.org/stable/gallery/statistics/hist.html).
  Official examples for empirical distribution visualization.
- SciPy, [Statistical
  Functions](https://docs.scipy.org/doc/scipy/reference/stats.html). Tested
  distribution objects, fitting methods, and statistical utilities for work
  beyond the educational implementations in this folder.
- Plotly, [3D Surface
  Plots](https://plotly.com/python/3d-surface-plots/). Interactive parameter
  surfaces and standalone HTML export.
- Streamlit, [API
  Reference](https://docs.streamlit.io/develop/api-reference). Widgets,
  caching, layout, and Plotly integration used by the local dashboard.

## Data Disclosure

No external dataset is used. Both Python scripts operate only on explicitly
identified synthetic data.
