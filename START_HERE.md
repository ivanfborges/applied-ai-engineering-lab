# Start Here

This file explains how to use this repository from day one.

## Current Goal

Build a professional, public GitHub repository that documents a deep study path in Data Science and AI Engineering, with the purpose of:

- strengthening theory for senior-level interviews;
- converting daily study into portfolio material;
- creating reusable notes, notebooks and implementations;
- supporting LinkedIn content without turning the feed into a daily study diary;
- making the repository a visible technical asset for recruiters and hiring managers.

## Recommended Weekend Setup

Before starting the first study day:

1. Create a local folder:

```bash
mkdir applied-ai-engineering-lab
cd applied-ai-engineering-lab
```

2. Copy all Markdown files from this starter pack into the folder.

3. Initialize Git:

```bash
git init
```

4. Open the folder in VSCode:

```bash
code .
```

5. Create the remote repository on GitHub.

Suggested repository name:

```text
applied-ai-engineering-lab
```

6. Add the remote:

```bash
git remote add origin https://github.com/ivanfborges/applied-ai-engineering-lab.git
```

7. Make the first commit:

```bash
git add .
git commit -m "Initialize applied AI engineering study lab"
git branch -M main
git push -u origin main
```

## Daily Flow

### Step 1 — Study in ChatGPT

Open ChatGPT in the browser or mobile app and paste:

1. the content of `STUDY_CONTEXT.md`;
2. the content of `DAILY_STUDY_PROMPT.md`;
3. the topic of the day from `ROADMAP.md`.

Example:

```text
I am starting Day 1 of my study roadmap.

Context:
[paste STUDY_CONTEXT.md]

Daily prompt:
[paste DAILY_STUDY_PROMPT.md]

Topic of the day:
Day 1 — AI/ML/GenAI landscape and roadmap overview
```

Use ChatGPT as the professor/mentor: ask questions, request examples, clarify concepts and challenge the explanation.

### Step 2 — Implement in Codex / VSCode

Open VSCode in the repository folder and use Codex with `CODEX_PROMPT.md`.

Tell Codex to read:

- `STUDY_CONTEXT.md`
- `ROADMAP.md`
- `REPO_STRUCTURE.md`
- `CODEX_PROMPT.md`

Then provide the topic of the day and the study output generated by ChatGPT.

### Step 3 — Review and Run

Before committing:

- read the generated Markdown files;
- run Python examples;
- fix broken imports or unclear explanations;
- ensure the README is professional;
- remove generic or superficial text.

### Step 4 — Commit

Use a clear commit message:

```bash
git add .
git commit -m "Add AI landscape study notes"
git push
```

## Weekly Flow

At the end of each week:

1. Review all topics studied.
2. Improve module README files.
3. Choose 1 or 2 strong insights for LinkedIn.
4. Avoid posting every daily note.
5. Keep LinkedIn posts short and accessible.
6. Leave technical depth in the GitHub repository.

## Important Principle

The repository is the technical depth.

LinkedIn is the distribution layer.

Do not try to put every mathematical detail in LinkedIn. Use LinkedIn to create interest, authority and conversation. Use GitHub to prove depth.
