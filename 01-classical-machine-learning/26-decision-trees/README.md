# Decision trees: impurity, splits, and pruning

A classification tree repeatedly asks whether one numeric feature is at most a threshold. Each answer sends a row to a smaller region, ending at a leaf whose prediction is the training majority class there. This greedy partitioning can capture threshold effects and interactions in tabular data without scaling features. A single tree is also a useful inspectable baseline, though small data changes can alter its structure.

## What the executed comparison shows

The example splits 600 synthetic rows into 360 training, 120 validation, and 120 test rows. It uses validation accuracy to select a pruning penalty from the training-set cost-complexity path, then reports test accuracy once. In this run, the unrestricted tree had 72 leaves and 1.000 training accuracy; the fixed pre-pruned tree had 7 leaves and the validation-pruned tree had 13. Exact configuration and results are in [notes.md](notes.md#executed-synthetic-comparison). The possible explanation and its limits are **for author review**.

## Key takeaways

- Gini and entropy measure class mixture; a split is scored by the parent impurity minus the child impurities weighted by their sample counts.
- A greedy best split is local. It does not guarantee the globally best tree.
- Deeper trees can fit training noise. Depth and leaf-size limits constrain growth; cost-complexity pruning removes branches after growth.
- Choose complexity with validation or cross-validation, leaving the test set for final evaluation.
- Leaf class proportions and impurity-based feature importance are model summaries, not automatically calibrated probabilities or causal effects.
