# References

- Friedman, J. H. (2001). [Greedy Function Approximation: A Gradient Boosting Machine](https://doi.org/10.1214/aos/1013203451).
  *The Annals of Statistics*, 29(5), 1189–1232. Original treatment of boosting
  as greedy function approximation and loss-directed optimization.
- [scikit-learn: Gradient-boosted trees](https://scikit-learn.org/stable/modules/ensemble.html#gradient-boosting).
  Official guide to classic gradient boosting, mathematical formulation,
  shrinkage, and tree capacity.
- [scikit-learn: GradientBoostingRegressor](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.GradientBoostingRegressor.html).
  Parameters, loss choices, staged predictions, and implementation notes.
  The executed example used scikit-learn 1.9.0; the stable documentation
  can advance independently.

The runnable examples use only synthetic, code-defined data and need no
dataset download. No external dataset is claimed as an evaluation source.
