# Study and Publication Methodology

This repository is built sequentially from the public roadmap. Each completed
topic passes through a study, implementation, validation, and editorial
workflow before it is presented as portfolio material.

## Workflow

1. **Topic selection:** the author selects the next topic from
   [`ROADMAP.md`](../ROADMAP.md) and studies the modules in sequence.
2. **AI-assisted study:** ChatGPT is used to help structure theory,
   mathematics, practical applications, limitations, interview questions, and
   possible experiments.
3. **Human review:** the author reviews the study material, preserves working
   notes and publication drafts locally, and decides which ideas deserve a
   public implementation.
4. **Implementation:** Codex is used as a coding and editorial copilot to
   organize documentation, implement examples, propose tests, and generate
   topic-specific visualizations.
5. **Validation and curation:** examples and relevant tests are run locally,
   relative links are checked, generated assets are curated, and proposed
   experiments are kept distinct from experiments that were actually
   executed.
6. **Publication:** only reviewed material is versioned. The root README is
   updated to reflect actual progress rather than planned work.

## Public Evidence

Depending on the topic, the public result may include:

- technical notes connecting theory to implementation;
- small executable examples and first-principles implementations;
- deterministic synthetic experiments;
- tests for reusable numerical or application logic;
- selected visual previews with reproducible generators;
- interview questions tied to the studied concepts;
- observed results, interpretation, trade-offs, and limitations.

Not every topic requires the same files. The technical question determines the
appropriate structure.

## Use of AI

AI tools assist research, drafting, implementation suggestions, visualization,
and editorial refinement. The author remains responsible for reviewing the
published material and for the technical decisions, executed experiments,
interpretations, and conclusions.

Raw study-session output, personal context, operational prompts, social-media
drafts, and internal review plans are kept locally and are not treated as
finished portfolio artifacts.
