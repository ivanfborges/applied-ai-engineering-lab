# References

- [SciPy: linkage](https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.linkage.html)
  — merge matrix format, linkage definitions, tie ambiguity, Euclidean restrictions
  and complexity of the unstructured algorithms.
- [scikit-learn: AgglomerativeClustering](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.AgglomerativeClustering.html)
  — complete trees, `children_`, `distances_`, connectivity and Ward/metric compatibility.
- [SciPy: cut_tree](https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.cut_tree.html)
  — partitions by merge order, cluster count or height.
- [SciPy: dendrogram](https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.dendrogram.html)
  — leaves, merge heights and contracted nodes; the visual tests verify incremental
  branch geometry against this reference.
- [Matplotlib: PillowWriter](https://matplotlib.org/stable/api/_as_gen/matplotlib.animation.PillowWriter.html)
  — GIF export without FFmpeg.
- [Plotly: sliders](https://plotly.com/python/sliders/)
  — selecting precomputed states without a Python server.
- [Plotly: interactive HTML export](https://plotly.com/python/interactive-html-export/)
  — embedding JavaScript in standalone offline documents.
- [Daniel Müllner, Modern hierarchical, agglomerative clustering algorithms (2011)](https://arxiv.org/abs/1109.2378)
  — algorithmic background for efficient hierarchical clustering.

Official API pages consulted on 2026-10-29. The live stable pages can describe
newer releases than the execution environment; measured package versions are
retained in [notes.md](notes.md). This study downloads no external dataset.
