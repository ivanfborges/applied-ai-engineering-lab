# References and implementation boundaries

Primary sources checked on November 6, 2026. No external dataset is downloaded;
all interactions and metadata are generated by the public example.

- Rendle, Freudenthaler, Gantner and Schmidt-Thieme (2009),
  [BPR: Bayesian Personalized Ranking from Implicit Feedback](https://proceedings.mlr.press/r7/rendle09a.html).
  Original pairwise criterion and its application to factorization. The example
  uses a shuffled-positive/uniform-unseen educational SGD schedule, not an exact
  reproduction of the paper's bootstrap learning algorithm or experiments.
- Hu, Koren and Volinsky (2008),
  [Collaborative Filtering for Implicit Feedback Datasets](https://yifanhu.net/PUB/cf.pdf).
  Preference/confidence distinction and alternating least-squares factorization.
  Provides the conceptual comparison in the notes; no ALS experiment is claimed.
- scikit-learn,
  [TruncatedSVD API](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.TruncatedSVD.html).
  Uncentered low-rank transformation, randomized solver, components and
  inverse/reconstruction interpretation. The recorded execution used version
  1.9.1; the stable documentation URL can evolve.

The observed numbers and synthetic generator are local study evidence, separate
from results reported in these publications. See the [dated record](README.md)
for configuration and **author review required** interpretation candidates.
