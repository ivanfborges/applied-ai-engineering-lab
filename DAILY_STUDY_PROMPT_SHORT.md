# Daily Study Prompt — Short Version

Use this version on busy days when there is less time available.

Replace `[TEMA_DO_DIA]` with the topic from `ROADMAP.md`.

---

```text
Topic of the day:
[TEMA_DO_DIA]

Act as my senior technical mentor in Data Science and AI Engineering.

I want to study this topic in 30–60 minutes with focus on:
- theory;
- mathematics/statistics/logical foundations;
- practical application;
- technical interviews;
- GitHub portfolio;
- short LinkedIn content.

Assume I am already a Senior Data Scientist / Applied AI Engineer working with Python, SQL, GCP, Vertex AI, BigQuery, Gemini, RAG and agents. Do not give me beginner-level explanations. I want enough depth to defend the topic in a senior technical interview.

Generate:

1. conceptual explanation;
2. mathematical/statistical/logical foundations;
3. when to use and when not to use;
4. common mistakes;
5. comparison with related methods;
6. practical Python example;
7. from-scratch implementation if useful;
8. senior interview questions and answers;
9. GitHub file structure;
10. short README in English;
11. short LinkedIn post idea in Portuguese;
12. 30–60 minute execution checklist.

Do not invent benchmark results. Use simple, executable and useful examples.
```
